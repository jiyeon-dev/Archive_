# Archive_

책과 강의 내용을 브랜치 단위로 정리하는 개인 학습 아카이브입니다.

각 브랜치는 하나의 책 또는 강의를 기준으로 관리합니다. `main` 브랜치는 전체 목록과 진행 상태를 확인하는 인덱스 역할만 합니다.

## 관리 기준

- `시작일`: 정리를 시작한 날짜
- `종료일`: 마지막 챕터 또는 강의 정리를 마친 날짜
- `상태`: 예정, 진행 중, 완료, 보류
- `카테고리`: 주제별 탐색을 위한 분류
